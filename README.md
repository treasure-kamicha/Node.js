## DESCRIPTION
 A Node.js project demonstrating fundamental backend development concepts, including file system management , HTTP web server creation, password generation, and automated email transport with Nodemailer.

 ## TECH STACKS

 Javascript
 HTML

 ## USAGE

To run any of the scripts, open your terminal/PowerShell in the project folder and execute the corresponding command:
node hello-world.js
node server.js
node file-system.js
node password-generator.js
